# 白川郷・新穗高・平湯溫泉 交通資訊彙整

> 收集日期：2026-07-11｜狀態：初步資料收集，尚未整合成行程
> 目的：確認能否從富山/高岡方向抵達白川郷合掌村，並串接新穗高纜車、平湯溫泉

## 1. 路線總覽（規劃方向）

```
高岡駅 / 富山駅 ──(加越能バス「世界遺産バス」)──> 白川郷
富山駅 ──(富山地鉄 高速バス「高山線」)──> 白川郷 ──> 高山
高山 / 平湯溫泉 ──(濃飛バス)──> 新穗高ロープウェイ
```

兩家業者（加越能バス／富山地鉄）可互相搭配，白川郷是轉乘樞紐。

### 世界遺産バス（高岡・城端・五箇山・白川郷線）

- 路線：高岡駅前 → 新高岡駅 → 城端駅 → 五箇山（相倉口・菅沼）→ 白川郷
- 主要票價（高岡駅/新高岡駅出發）：
  - 城端駅：840円
  - 相倉口：1,100円
  - 菅沼：1,300円
  - 白川郷：**2,000円**
- 優惠票券：
  - 五箇山・白川郷 単程フリーきっぷ：2,000円（2日有效，兒童半價）
  - 五箇山・白川郷 往復フリーきっぷ：3,500円（2日有效，兒童半價）
  - 購買連結：https://toyama.visit-town.com/visittour/sekaiisanbus-goka 、 https://toyama.visit-town.com/visittour/sekaiisanbus-gokasira
- ⚠️ 注意：部分班次常態停駛（例：高岡駅16:00發車、白川郷07:00發車），需查最新時刻表
- 2026/4/1 起票價將調整（企業／定期票部分）
- 時刻表 / 運賃表頁面：https://www.kaetsunou.co.jp/regular/fare/
- 客服電話：0766-22-4886（另一資料來源顯示 0766-21-0950，9:00–18:00，建議實際去電前再次確認正確分機）

## 3. 富山地方鉄道（Toyama Chihou Railway）

- 官網：https://www.chitetsu.co.jp/
- 高速バス「高山線」：富山駅 ⇄ 白川郷 ⇄ 高山濃飛バスセンター
  - 頁面：https://www.chitetsu.co.jp/?page_id=22436
  - 範例班次：富山駅南口 12:00発 → 白川郷 13:30 → 高山濃飛バスセンター 14:20着
  - 車輛為4列座椅（最後排5列）
  - 高速バス預約中心（富山線）：(076) 433-4890，營業 8:30–19:00
- 富山地鉄本身另有立山黑部阿爾卑斯路線等（與本次白川郷行程無直接關聯，暫不列入）

## 4. 濃飛バス（Nouhi Bus）—— 高山／白川郷／平湯溫泉／新穗高

- 高山〜白川郷〜金沢・富山・高岡線：https://www.nouhibus.co.jp/route_bus/shirakawago/
- 高山〜白川郷〜富山線（bushikaku 查詢）：
  - 富山→白川郷→高山 12:00発
  - 高山→白川郷→富山 14:30発
- 高山・平湯溫泉 → 新穗高ロープウェイ：https://www.nouhibus.co.jp/route_bus/shinhotaka-line/
  - **從高山/平湯溫泉上車不需預約**
  - 僅「中尾焼岳登山口〜新穗高溫泉」區間上車往新穗高纜車方向者，需事前預約：濃飛バス高山営業所 TEL 0577-33-7780（限前一日18時前受理）
  - 車資：飛驒高山→奧飛驒溫泉鄉 單程，平湯 1,530円、新穗高纜車 2,100円
- 優惠套票：
  - 高山バスセンター⇄新穗高纜車 2日/3日フリー乗車券 + 新穗高纜車（第1・第2）來回票 套票
  - 2026/4/1–2027/3/31 有效：高山發 2日フリープラン 大人10,500円／兒童（小学生）5,250円
  - 套票頁：https://www.nouhibus.co.jp/marugoto_value_ticket/ 、 https://www.nouhibus.co.jp/ticket/

## 5. 白川郷點燈活動（第41回 白川郷ライトアップ）

- 來源：https://shirakawa-go.gr.jp/events/438/
- 日期：**2027年1月11日（一）、17日、24日、31日**（共4天）
- 時間：17:30–19:30
- 地點：白川村荻町地区內
- **完全預約制**，無預約者當日無法入場
- 詳細預約方法：預計 2027年9月初 公佈於官方網站，各旅行社/設施屆時個別受理預約
- 費用：未公告，將於9月初一併公佈
- 注意事項：
  - 禁止無人機空拍
  - 點燈當日日間，觀光巴士需於 14:00 前入場、16:00 前離場
  - 停車另需預約「白川村駐車場預約服務」
  - 若遇大寒波交通中斷可能取消
- 聯絡方式：白川郷ライトアップ委員会 TEL 05769-6-1013（9:00–17:00）
