# JP Travel × search-flights Integration Guide

## Quick Start

### 1. 使用 search-flights 技能搜尋機票

在 JP Travel 項目中，直接使用技能路徑：

```bash
python3 ./.claude/skills/search-flights/search.py <args>
```

或簡寫：
```bash
python3 search-flights/search.py <args>
```

### 2. 常見用法示例

#### 模式一：找固定天數的最便宜出發日
```bash
python3 search-flights/search.py TPE KIX 2026-10-01 2026-10-31 5 12000 CI,BR --nonstop
```
找 10月出發、5天行程、預算 12000 TWD、直飛的最便宜選項。

#### 模式二：看整月日期組合的價格矩陣
```bash
python3 search-flights/search.py --grid TPE KIX 2026-10-15 2026-10-25 2026-10-20 2026-10-26 CI,BR
```
看 10/15-25 出發、10/20-26 回程的所有組合價格。

#### 模式三：跨季價格走勢
```bash
python3 search-flights/search.py --graph TPE JP 2026-09-01 2026-11-30 5 7
```
看 9月～11月整季的每日最低價（5～7天行程）。

### 4. 航空公司篩選

預設支援: CI (華航), BR (長榮), JX (星宇), MM (樂桃), TR (酷航), IT (台虎), GK (捷星), JL (JAL), NH (ANA)

指定特定航空: `CI,BR,JX` 或留空表示所有

直飛: `--nonstop` 旗標

### 5. 整合進行程規劃

流程：
1. 用 `--graph` 模式看跨月價格走勢 → 找便宜月份
2. 用 `--grid` 模式看該月的出發/回程日組合 → 找最佳日期窗口
3. 用掃描模式驗證該日期的詳細航班與推薦回程

例：
```bash
# Step 1: 找最便宜的月份
python3 search-flights/search.py --graph TPE KIX 2026-09-01 2026-11-30 5 7

# Step 2: 縮小到該月的日期組合
python3 search-flights/search.py --grid TPE KIX 2026-10-15 2026-10-25 2026-10-20 2026-10-26 CI,BR

# Step 3: 詳細掃描最低價日期
python3 search-flights/search.py TPE KIX 2026-10-20 2026-10-20 5 12000 CI,BR --nonstop
```

## 輸出解讀

### Scan Mode 輸出

```
━━ 2026-10-20 (週二) 出發 ━━━━━━━━━━━━━━━━━━━━━━━
航班 | 去程時間 | 停靠 | 回程推薦
IT702 07:45→11:30 | 直飛 | 票價 TWD 10,130 | 便宜

推薦回程選項:
- 2026-10-25 BR701 12:20→09:50 (同日到) | +3,200 = 13,330
- 2026-10-26 CI501 14:30→11:20 (同日到) | +2,800 = 12,930
```

**評級說明**:
- 超值 (★★★★★) — 極低價，立即購買
- 便宜 (★★★★) — 低於正常，建議購買
- 一般偏低 (★★★) — 接近 Google 典型低點
- 一般 (★★) — 中等價格
- 偏高 (★) — 高於正常，除非日期限制
- 高 — 避免購買，等待降價

### Grid Mode 輸出

```
出發日\回程日  | 10/20 | 10/21 | ... | 10/26
10/15          | 9,500 | 9,800 | ... | 11,200
10/16          | 9,200 | 9,600 | ... | 10,900
...
```

快速掃描整月矩陣，找最低價組合。

### Graph Mode 輸出

```
日期 | 最低價(TWD)
2026-09-01 | 13,200
2026-09-02 | 13,100
...
2026-10-15 | 9,500  ← 價格谷底
...
```

看長期價格走勢，判斷是否應等待進一步下跌。

## 技術細節

### Rate Limiting & Retry
- 掃描多天時，每天間隔 1.5s，避免被限流
- API 超時自動重試（最多 3 次）
- Grid/Graph 模式速度快（單次 API，~2 秒）

### 日期格式
- 輸入: YYYY-MM-DD (e.g., 2026-10-20)
- 輸出中日本日期表示: 週次 (e.g., 週二)

### 貨幣
- 臺灣出發: TWD (新台幣)
- 預算參數單位: TWD

## 故障排除

| 症狀 | 原因 | 解決 |
|------|------|------|
| 回傳空值 | API 限流 | 增加間隔，稍後重試 |
| 票價差異大 | 日期範圍太廣 | 用 --grid 先縮小日期 |
| 回程選項少 | 日期限制太嚴 | 寬鬆回程日期範圍 |
| 直飛班次無 | 路線有限 | 移除 --nonstop 看轉機選項 |
