# 富山×白川郷×飛驒 8天7夜行程草案

> 基準：TPE⇄TOY，中華航空每週僅週一/週四各一班，故只能組成 4天3夜／5天4夜／8天7夜
> 本方案採 **8天7夜**，以「1/17 白川郷点燈」為主軸，前後各留緩衝日應對冬季天候風險
> 假設機票：去程 1/14（四）CI370 TPE 13:30→TOY 17:20；回程 1/21（四）CI171 TOY 11:55→TPE（時刻沿用你已查詢的班次，回程週別需另行核價）

## 為什麼這樣排

1. **點燈日(1/17)排在行程中段**，前後都還有緩衝天數，不會像5天4夜方案那樣「點燈當晚→隔天一早衝機場」硬卡在一起。
2. **新穗高纜車安排在倒數第3天（Day6）**，並把Day7留成天候備案／移動日，降低「纜車停駛+隔天班機」兩個高風險項目疊加的機率。
3. **Day7 最後一晚睡在富山**，讓Day8只需處理「富山市區→機場」這種短距離、低風險的移動，不必仰賴白川郷/高山方向的長途巴士銜接早班機。
4. 高岡、五箇山安排在去程（Day2–3），順路且不走回頭路；回程走高山→平湯→富山，形成單向路線不折返。

## 待確認事項（出發前必做）

- [ ] 白川郷ライトアップ 1/17 場次的預約：確認公告時間（推測應為2026年9月初開放預約，需近期再次核實官網說法是否為擷取誤讀）
- [ ] 世界遺産バス／富山地鉄高速バス／濃飛バス：出發前1–2週重新核對冬季時刻表（12月中常改點）及當週路況/停駛公告
- [ ] 新穗高纜車官網天候營運狀態（強風常在冬季下午停駛，建議安排上午時段搭乘）
- [ ] 白川村駐車場預約服務（若考慮租車，點燈日停車需另外預約）
- [ ] 回程 CI171 實際週次班表與確切時間（本草案沿用你已查到的 11:55，但回程日期換到下週四需另核價）
- [ ] 各晚住宿（白川郷荻町民宿常需提早3–6個月預約，尤其點燈日前後）

## 與 5天4夜方案的差異

| 項目 | 5天4夜 | 8天7夜（本方案） |
|------|--------|------------------|
| 點燈日後緩衝 | 無，隔天早班機 | 有，中間隔3天才登機 |
| 新穗高纜車風險 | 若安排最後一天則高 | 排在Day6，Day7備案 |
| 可加景點 | 幾乎排滿，無彈性 | 高岡、五箇山、平湯溫泉都可從容納入 |
| 適合對象 | 只能請5天假 | 想從容體驗、天候風險承受度低者 |
